# 人狼GM（jinrou）

1台の端末を回して遊ぶ、**ローカル専用**の人狼ゲームです。

- ライブ: https://jinrou.mct-official.com/
- 公開方法: GitHub リポジトリ → Cloudflare Workers（静的アセット＋カスタムドメイン）

## モード

- **ローカルモード**: 1台の端末を回して遊ぶ（従来通り）
- **オンラインモード**: 部屋コード（4文字）を共有して各自の端末から参加。役職はサーバー側で配られ、自分の役職だけが見えます。夜の行動と投票も各自の端末から行います

## 遊び方（ローカル）

1. 同じ場所に集まったプレイヤー（4〜15人）で人数と名前、役職構成を設定する
2. 端末を1人ずつ回して、自分の役職をこっそり確認する
3. 夜：端末を回して、人狼の襲撃・占い・騎士の護衛・霊媒をGM（アプリ）が順に案内する
4. 朝：GMが昨晩の結果を発表する
5. 昼：みんなで議論（タイマー付き）→ 端末を回して投票 → 処刑
6. 人狼が全員いなくなるか、人狼と村人側が同数以上になるまで繰り返す

## 役職

人狼 / 狂人 / 占い師 / 騎士 / 霊媒師 / 村人（人数に応じて自動構成、カスタムも可）

## 方針（重要）

- **チャット機能はありません。** 議論は対面や別の通話手段で行ってください。サーバー（Cloudflare Durable Objects）が扱うのは、部屋への参加・役職配布・夜の行動・投票といったゲーム進行データだけです。自由な文章を送れる仕組みは意図的に入れていません
- ローカルモードではサーバーにデータを送りません。オンラインモードの部屋データはゲーム進行のためだけに保持されます

## 技術構成

- フロント: `public/index.html`（単一ファイル）
- サーバー: `worker.js`（Cloudflare Workers + Durable Objects、部屋ごとに1インスタンス）
